# 2nd Inversion Musical School

A modern music school platform with AI-powered practice system, smart booking, and admin dashboard.

## Features

- **Class Name**: 2nd Inversion Musical School
- **Instructor**: instructor all in one
- **Admin**: Ajinkya Amrule
- **Class Timings**:
  - Morning: 3:00 AM - 12:00 PM
  - Evening: 3:00 PM - 9:00 PM
- **Holiday**: Monday

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Recharts (for analytics)
- JWT (authentication)
- MongoDB (database)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- **Home**: Main landing page with hero, instructor info, schedule, and booking
- **Header**: Navigation with school name
- **Hero**: Welcome section for 2nd Inversion Musical School
- **Instructor Info**: Details about "instructor all in one"
- **Class Schedule**: Available classes with timings (excludes Monday)
- **Booking System**: Form to book classes with admin contact info
